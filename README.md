# Bili.Dynamic.AutoDel

一个用于清理 Bilibili 转发动态的 Tampermonkey / 油猴用户脚本。

本脚本目前仅在 **Microsoft Edge 浏览器** 中通过测试。其他浏览器尚未测试，
适配性未知。

本项目是基于原作者 **monSteRhhe** 的
[bilibili-dynamic-del](https://github.com/monSteRhhe/bilibili-dynamic-del)
修改而来。原作者的项目提供了 Bilibili 转发动态清理功能，本仓库在此基础上
重写了日期筛选、扫描、预览和删除流程。

## 功能

当前版本只保留以下两个油猴菜单：

1. **选择指定日期之间的动态**
   - 输入开始日期和结束日期。
   - 扫描该日期范围内的转发动态。
   - 扫描窗口实时显示已扫描数量和候选数量。
   - 扫描过程中可以停止扫描，并立即预览已经扫描到的候选动态。
   - 扫描完成后显示预览窗口，不会自动删除。
   - 预览中显示动态文字、图片、源动态作者、UID、日期和链接。
   - 支持全选、全不选和手动多选。
   - 只有用户确认后才会发送删除请求。

2. **暂停 / 继续当前任务**
   - 删除任务执行过程中可以暂停和继续。
   - 扫描阶段建议使用扫描窗口中的“停止扫描并预览”按钮。
   - 删除请求之间会保留时间间隔，以降低触发 Bilibili 接口频率限制的概率。

## 安装

1. 在 Microsoft Edge 中安装 Tampermonkey（篡改猴）扩展。
2. 打开脚本文件：
   [`bili-dynamic-autodel.user.js`](./bili-dynamic-autodel.user.js)
3. 点击“安装”。
4. 登录 Bilibili 后，在任意 Bilibili 页面打开油猴菜单，选择
   **选择指定日期之间的动态**。

## 使用说明

日期判断使用的是**用户转发动态自身的发布时间**，不是源动态的发布时间。
开始日期和结束日期均包含在扫描范围内。

扫描得到的候选动态只会进入预览列表，不会自动删除。请在预览窗口检查动态内容，
勾选确认后再点击删除。

删除请求属于对账号内容的实际操作。请确认登录账号、日期范围和候选列表无误，
并避免短时间内重复启动多个任务。

## 修改内容

相对于原项目，本修改版主要做了以下调整：

- 删除“自动判断”功能。
- 删除“指定用户”功能。
- 删除“打开设置”功能。
- 删除取关功能及其存储、请求和相关代码。
- 将按天数删除改为按开始日期和结束日期筛选，并使用用户转发动态自身的发布时间。
- 增加扫描状态窗口和实时扫描进度。
- 增加扫描失败、扫描完成和扫描停止提示。
- 增加扫描阶段的停止并预览功能。
- 增加动态文字、图片和作者信息预览。
- 增加全选、全不选和多选删除。
- 增加删除任务暂停 / 继续功能。
- 增加 API 请求和逐条删除之间的时间间隔。
- 修复日期输入为空、非法日期、重复弹出输入框等问题。
- 修复删除请求参数、CSRF Cookie 读取和失败信息显示问题。
- 增加重复删除保护，避免同一条动态重复提交删除请求。
